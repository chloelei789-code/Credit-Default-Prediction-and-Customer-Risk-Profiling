# Data

The raw dataset is not committed to this repository.

## Source

UCI Machine Learning Repository: **Default of Credit Card Clients**

Dataset page:
https://archive.ics.uci.edu/dataset/350/default%2Bof%2Bcredit%2Bcard%2Bclients_dataset

Citation:

Yeh, I.-C. (2009). *Default of Credit Card Clients* [Dataset]. UCI Machine Learning Repository. DOI: 10.24432/C55S3H.

## Local setup

Download the dataset and place the CSV file at:

```text
data/default_of_credit_card_clients_dataset.csv
```

The notebook also supports the Windows paths used during development, but the repository-relative path above is recommended for reproducibility.
